# Big Data Sales Analytics Using Hadoop and MapReduce

## Project Overview

This project analyzes e-commerce transaction data using Hadoop and MapReduce to identify sales trends and generate business insights. The objective was to process large-scale retail data and calculate sales performance across product categories within a distributed computing environment.

## Dataset

Online Retail Transaction Dataset (E-Commerce Sales Data)

The dataset contains transactional sales records including product information, quantities, prices, and sales values.

## Technologies Used

- Hadoop
- HDFS
- MapReduce
- MongoDB
- Microsoft Excel

## Project Objectives

- Process large-scale transaction data using Hadoop.
- Store data within HDFS.
- Calculate total sales by product category.
- Generate business insights from transaction patterns.
- Store processed outputs in MongoDB.

## Methodology

### 1. Data Preparation
- Cleaned and prepared transaction records.
- Validated dataset structure and consistency.

### 2. Distributed Storage
- Uploaded datasets into HDFS.
- Organized data for distributed processing.

### 3. MapReduce Processing
- Implemented MapReduce jobs to calculate total sales.
- Aggregated sales values by category.

### 4. Data Storage
- Stored processed outputs in MongoDB.
- Verified analytical results.

## Key Outcomes

- Successfully processed retail transaction data using Hadoop.
- Generated category-level sales summaries.
- Demonstrated distributed data processing using MapReduce.
- Produced business insights from sales performance trends.
